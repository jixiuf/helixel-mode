#+TITLE: helixel-mode
#+OPTIONS: toc:nil num:nil

Helix-style modal editing for Emacs.  Requires Emacs ≥ 29.1.

Helixel is *selection-first*: you select a region first, then act on it.  This is the opposite of
Vim's operator-pending model (~d3w~ = "delete 3 words" where the operator comes first).  In Helixel
you type ~w w w ; d~ or ~3wd~ — select three words, then delete.

** Install

#+begin_src elisp
  (use-package helixel
    :vc (:url "https://github.com/jixiuf/helixel-mode")
    :config (helixel-mode))
#+end_src

Or manually:

#+begin_src elisp
  (add-to-list 'load-path "/path/to/helixel-mode")
  (require 'helixel)
  (helixel-mode)
#+end_src

Quick try:

#+begin_src sh
  make run
  # or
  emacs -Q -L . -l helixel.el --eval '(progn (helixel-mode) (which-key-mode))'
#+end_src

** Quick Setup

#+begin_src elisp
  ;; Enable PCRE-style regexp in search (/ and ?) via pcre2el
  ;; You need install optional "pcre2el" first
  (setq helixel-search-pcre t)
#+end_src

See ~M-x customize-group RET helixel RET~ for all options.

** Highlights
*Why helixel?*  Beyond Helix-compatible keybindings, helixel adds features that
neither the Helix editor nor other Emacs Helix simulators provide:

- *Smart dot-repeat* (~.~ / ~M-.~) :: Repeats edits for *all* selection kinds
  (search, movement, textobj, find-char), not just line-wise.  Prefix modes:
  ~3.~ (N times), ~0.~ (to end), ~C-u .~ (all-buffer), ~-.~ (reverse),
  ~C-u - 3 .~ (one-time reverse).  ~M-.~ previews without editing.
- *Action cycle* (~;~ / ~C-;~) :: ~;~ marks the *full span* of each
  movement/edit group.  ~C-;~ pushes mark to the *start position*.  Sessions
  auto-group by type (~ww~ is one group, ~jj~ another).  After ~p~ / ~r~,
  re-selects pasted or replaced text.  Configurable per-category.
- *Motion repeat* (~,~) :: Repeats any motion (find-char, pair, match, search)
  from a self-contained snapshot — survives intervening ~/~ without losing
  context.
- *Chain recording* (~@~) :: Records a compound sequence (helixel + vanilla
  commands) and replays at each target via ~.~.  Insert-mode typing captured
  verbatim, no double-replay.
- *Multi-cursor* (~s~) :: Each fake cursor has its *own* ~kill-ring~,
  ~mark-active~, ~.~ history, and ~;~ event ring.  ~@~ + multi-cursor
  broadcasts chains to every cursor in one undo step.  ~g v~ restores last
  cursor layout from a 16-deep history stack.



Search-and-replace with dot-repeat:
#+begin_src text
  /hello RET   search "hello"
  cWORLD ESC   change to "WORLD"
  .            next "hello" → "WORLD"
  3.           next 3 "hello"s → "WORLD"
  M-.          preview next match (no edit)
  .            then edit current "hello" after preview
  -.           reverse direction, repeat (personally I bind negative-argument on `C-h`)
  0.           repeat to end of
#+end_src

Multi-cursor — edit every occurrence at once:
#+begin_src text
  miw          select inner word
  s s          spawn cursors at every occurrence
  cNEW ESC ESC change all to "NEW" in one undo step
#+end_src

Search-and-replace with multi-cursor:
#+begin_src text
  /foo RET     search "foo"
  s s          spawn cursors at every match
  cbar ESC ESC change all to "bar" in one undo step
#+end_src
Search-and-replace with multi-cursor:
#+begin_src text
  /foo RET     search "foo"
  cbar ESC     change all to "bar" in one undo step
  s s          spawn cursors at every match
  s .  ESC     repeat last edit at all cursors
#+end_src

Insert "hello" at each line with multi-cursor
#+begin_src text
  xxx            select  3 lines
  s s            spawn cursors at every match
  ihello ESC ESC insert hello ate each line
#+end_src

Action cycle — reselect spans of past motions:
#+begin_src text
  w w          forward two words
  ;            select full span of w w
  j j          down two lines
  ;            select full span of j j
  ;            select full span of w w (older)
  b b          backward two words
  C-;          mark start of b b (no full span)
#+end_src

Motion repeat — repeat any motion from a snapshot:
#+begin_src text
  %            jump to matching bracket
  ,            outward one nesting level
  ,            outward again
  ;            select the traversed span
  C-;          Try C-; see the different bewteen ";" and "C-;"
#+end_src

Pair/structure movement with ~]~ / ~[~ / ~}~ / ~{~:
#+begin_src text
  ] (          forward to next (...)'s closing end
  [ {          outward to enclosing {'s opening
  ] p          forward to next paragraph end
  ,            next paragraph
  ;            select the span
#+end_src

** Key Reference

| Key                     | Action                                                                              |
|-------------------------+-------------------------------------------------------------------------------------|
| ~h~ ~j~ ~k~ ~l~         | Move                                                                                |
| ~w~ ~b~ ~e~ ~W~ ~B~ ~E~ | Word / WORD forward, back, end                                                      |
| ~i~ ~a~ ~I~ ~A~ ~o~ ~O~ | Enter insert mode                                                                   |
| ~x~                     | Select current line; repeat to extend                                               |
| ~v~                     | Enter visual mode; ~ESC~ returns to normal                                          |
| ~d~ ~D~ ~c~ ~y~         | Delete / delete-no-kill / change / copy selection                                   |
| ~p~ ~P~                 | Paste after / before                                                                |
| ~r~ ~R~                 | Replace yanked / replace-char                                                       |
| ~S~                     | Swap regions (position-aware)                                                       |
| ~<~ ~>~                 | Indent left / right; repeats with ~.~                                               |
| ~u~ ~U~                 | Undo / redo                                                                         |
| ~/~ ~?~                 | Search forward / backward (regexp; ~M-r~ toggles literal)                           |
| ~f~ ~t~ ~F~ ~T~         | Find char / till char                                                               |
| ~n~ ~N~                 | Repeat search or find-char; ~N~ reverses direction                                  |
| ~,~                     | Repeat last motion ( ~/~ ~f~, ~t~, ~%~, ~[~, ~]~, ~{~, ~}~), ~-,~ reverse direction |
| ~;~                     | Action cycle — select span of last motion/edit                                      |
| ~C-;~                   | Mark cycle — push mark to original pre-motion cursor position                       |
| ~C-o~ ~C-i~             | Jump to older / newer position (global, cross-buffer)                               |
| ~%~                     | Jump to matching bracket, (Try ~,~ and ~;~ after ~%~)                               |
| ~m i~ ~m a~             | Text objects: inner / around (word, symbol, pair, quote, tag, function, block)      |
| ~m s~ ~m t~ ~m d~ ~m r~ | Surround: add, add-tag, delete, replace                                             |
| ~[~ ~]~ ~{~ ~}~         | Pair & structure movement (outward / forward)   (Try ~,~ and ~;~ after movement)    |
| ~@~ ~ESC~               | Chain recording: start / finish (~.~ replays at next target)                        |
| ~.~ ~M-.~               | Dot-repeat: repeat last edit / repeat last selection                                |
| ~g~                     | Goto prefix (~g g~ ~g d~ ~g r~ ~g i~ ~g y~ ~g .~ ~g ;~)                             |
| ~C-w~                   | Window prefix                                                                       |
| ~s~                     | Multi-cursor prefix (~s s~ spawn, ~s a~ add, ~s n~ next-like, ~s x~ per-line)       |

** Differences from Helix Native Keybindings

Helixel follows Helix conventions but some keys are remapped to accommodate
Emacs constraints and extra features.  The table below shows each Helix key
that differs, its Helix action, what helixel binds that key to, and which
helixel key provides the original Helix behavior.

| key           | Helix action                 | Helixel binds to                 | Helix feature via                 |
|---------------+------------------------------+----------------------------------+-----------------------------------|
| ~s~           | Select regex matches         | Multi-cursor prefix              | ~s r~                             |
| ~;~           | Collapse selection           | Action cycle (span + history)    | ~s ;~                             |
| ~,~           | Keep primary selection only  | Repeat last motion               | ~s ,~                             |
| ~M-.~         | Repeat last motion           | Preview repeat (select, no edit) | ~,~                               |
| ~S~           | Split selections on regex    | Swap regions                     | ~s d~ / ~s S~ (split)             |
| ~C~           | Copy selection to next line  | Same key (~C~) + also ~s a~      | Same purpose, different internals |
| ~Space~       | Space mode (picker menus)    | User leader key (~SPC~)          | —                                 |
| ~{~ / ~}~     | Move to prev/next empty line | Inner pair movement prefix       | ~[ p~ / ~] p~ (paragraph)         |
| ~g n~ / ~g p~ | Go to next/prev VCS change   | — (not bound)                    | —                                 |
| ~g .~         | Go to last modification      | Pick past edit to repeat         | (different meaning)               |
| ~g ,~         | Go to first modification     | — (not bound)                    | —                                 |
| ~q~ / ~Q~     | Record / replay macro        | — (not bound)                    | ~@~ (chain recording)             |
| ~C-u~         | Scroll half-page up          | — (not bound)                    | universal-argument via C-u        |
| ~C-d~         | Scroll half-page down        | — (not bound)                    | —                                 |
| ~-~           | — (not bound in Helix)       | Negative-argument prefix         | —                                 |

Helixel-only additions (no Helix equivalent):
- ~M-.~ :: Preview repeat — repeat last selection without editing (Helix ~M-.~ = repeat motion, helixel uses ~,~ for that)
- ~C-;~ :: Mark cycle — push mark to pre-motion cursor position
- ~BS~ / ~C-BS~ / ~M-BS~ :: Delete backward char/word in normal mode

Most multi-cursor operations are available under the ~s~ prefix.  When
multi-cursor mode is active, these keys also work as top-level bindings
(matching Helix): ~(~, ~)~, ~M-(~, ~M-)~, ~M-,~, ~K~, ~&~, ~_~, ~M--~, ~M-k~.
